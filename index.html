Asistente RAG · Python · Fragmentación con solape

Un fragmento nunca parte una idea por la mitad

El fragmentador no corta cada N caracteres a ciegas: acumula párrafos enteros y arrastra el último al siguiente fragmento, para que el contexto cruce la frontera entre dos trozos del índice.

def chunk_text(text, size=CHUNK_CHARS, overlap=OVERLAP_CHARS):
    """Trocea por párrafos acumulando hasta `size` caracteres, con solape."""
    paragraphs = [p.strip() for p in re.split(r"\n\s*\n", text) if p.strip()]
    chunks = []
    current = ""
    for para in paragraphs:
        …
        candidate = (current + "\n\n" + para) if current else para
        if len(candidate) <= size:
            current = candidate
        else:
            chunks.append(current)
            # solape: arrastra el último párrafo al siguiente fragmento
            tail = para if len(para) <= overlap else current[-overlap:]
            current = (tail + "\n\n" + para) if tail != para else para
    if current:
        chunks.append(current)
    return [c for c in chunks if len(c) >= 40]

Block Ethos · Tutor · TF-IDF

Un tutor que no inventa respuestas

El tutor responde solo desde el contenido de las lecciones: una búsqueda TF-IDF con la librería estándar de Python puntúa los fragmentos y compone la respuesta con los mejores, citando ruta, módulo y lección. Si ningún fragmento supera el umbral, lo dice honestamente y sugiere la lección más cercana en vez de inventar. El índice se cachea y solo se reconstruye cuando cambia el contenido — lo detecta una huella SHA-256 de las lecciones.

Block Ethos · Despliegue · Vite

La guarda que apagó toda la app

La plantilla trae una guarda: si al compilar falta la variable VITE_BACKEND_URL, la aplicación entera se sustituye por una página de «Missing BACKEND_URL». El 2 de noviembre una compilación sin esa variable dejó la app en esa página de error, aunque el backend y los datos estaban intactos. Se detectó comparando el bundle con el último bueno: el defectuoso tenía 0 ocurrencias de la URL del backend; el bueno, 21. La lección quedó en el proceso: nunca se empaqueta un despliegue sin verificar su contenido contra lo que promete.

Block Ethos · Flask · Validación

El 99999 que inflaba la XP

La experiencia suma la nota del quiz tal cual: sin un tope, un quiz_score de 99999 disparaba los niveles sin límite. La validación acepta solo números entre 0 y 100 — y excluye los booleanos, porque en Python True == 1 y se colaba como nota válida. El mismo criterio protege la actualización individual y la carga por lotes, y una prueba envía 99999, −5, «cien» y True para comprobar que los cuatro dan 400.
